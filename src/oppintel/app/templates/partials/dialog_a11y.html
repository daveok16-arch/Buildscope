{# Shared modal/dialog focus management for the mobile nav drawer and the mobile filter bottom sheets. One implementation so the three surfaces cannot drift apart. A modal dialog must do five things, and this helper does all five: 1. move focus into the dialog on open (first focusable, else the container); 2. keep Tab and Shift+Tab inside it (wrap at the ends); 3. make the rest of the page inert so nothing behind it is focusable or clickable; 4. close on Escape and return focus to the control that opened it; 5. lock body scroll while open. `inert` is supported in current Chrome/Edge/Firefox/Safari; where it is not, the Tab trap still keeps keyboard focus inside the dialog. The helper degrades rather than throwing. #}
